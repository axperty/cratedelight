# Pumpkin Slice Crate

Not sure how to get the ingredients for this crate? [Learn how to obtain pumpkin slices](https://farmersdelight.fandom.com/wiki/Pumpkin_Slices).

## Crafting Recipe

Place 9 pumpkin slices on the crafting table to get a pumpkin slice crate.

![Pumpkin Slice Crate Recipe](/assets/recipes/pumpkin_slice_crate_recipe.png)

::: tip Note
This crate is only available when you have the Farmer's Delight mod installed, and you are using Crate Delight with it.
:::
